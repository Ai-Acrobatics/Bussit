🚀 GETTING STARTED
══════════════════════════════════════════════════════════════════

1. Read SETUP.md for configuration instructions
2. Add API credentials to LLM_SECRETS:
   - TWILIO_ACCOUNT_SID
   - TWILIO_AUTH_TOKEN
   - TWILIO_PHONE_NUMBER
   - OPENAI_API_KEY
   - TELEGRAM_BOT_TOKEN (optional)
   - TELEGRAM_CHAT_ID (optional)

3. Install dependencies:
   npm install

4. Test the installation:
   ./test.js --all

5. Make your first call:
   ./call.js --to "+YOUR_PHONE" --task "Test call"
